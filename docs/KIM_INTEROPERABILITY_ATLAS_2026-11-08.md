## 1. Mission

Create a consent-aware, open, interoperable research network for the Matrixgame, Gaia Commons, LUMINI, and collective AI games.

The network should make research:
- discoverable across repositories and platforms;
- attributable to its source and author;
- machine-readable and portable between tools;
- independently reviewable and discussable;
- reproducible where code or data are involved;
- safe to share, with private and personal material kept private by default.

The acronym **KIM** is retained as used by the project owner; this document does not infer or redefine its expansion.

## 6. Cross-platform knowledge object model

The aim is not to copy whole accounts or chat logs into one public repository. Store small, attributable knowledge objects.

### Suggested record types

- `SourceRecord`: platform, source ID, title, canonical URL, author/owner, date observed, access mode, reuse rights, review state.
- `ArtifactRecord`: code, document, playlist, dataset, post, video, diagram, or simulation.
- `ClaimRecord`: statement, epistemic status, scope, units, assumptions, uncertainty.
- `EvidenceRecord`: source reference, measurement, publication, method, licensing, relevant excerpt or hash.
- `ModelRecord`: equations, parameter set, boundary conditions, solver, validation scope.
- `SimulationRun`: model version, code revision, seed, inputs, outputs, time step, logs.
- `AgentContribution`: agent ID/version, role, task, claims, evidence, challenges, abstentions.
- `ReviewRecord`: reviewer, tests performed, unresolved issues, human decision.
- `QuestRecord`: goal, prerequisites, action, success indicator, risks, learning outcome.

### Typed relationships

- `IMPLEMENTS`: code implements a model.
- `MODELS`: a model represents a scoped phenomenon.
- `DERIVES_FROM`: an equation or claim follows from another record.
- `SUPPORTS` / `CHALLENGES` / `CONTRADICTS`: evidence relationship.
- `TESTS`: test or experiment checks a claim or implementation.
- `RELATED_TO`: weak association without implying proof.
- `SUPERSEDES`: reviewed newer record replaces an older version for a specified purpose.
- `INSPIRED_BY`: an idea is conceptually inspired by a source but has not been validated by it.

A similarity score or repeated phrase is a discovery aid, not evidence of truth or equivalence.

## 7. Multi-agent exchange and discussion protocol

Each participating AI or human should receive the same versioned task and authorized evidence bundle. Contributions should be independent before synthesis.

Recommended sequence:

1. Source Steward registers source IDs, titles, access modes, licenses, and review state.
2. Research agents independently produce claims and source references.
3. Domain agents check physics, biology, ecology, climate, energy, software, and governance.
4. A Red Team identifies missing data, counterexamples, scope errors, and unit mistakes.
5. A deterministic validator checks schemas, units, ranges, and reproducibility.
6. A synthesis agent maps agreement and disagreement, but does not convert consensus into FACT.
7. A human reviewer accepts, revises, rejects, or abstains.
8. Public comments, posts, or cross-platform messages are drafted for review; publishing requires explicit approval.

Allowed outcomes include `PASS`, `WARNING`, `UNCERTAIN`, `ABSTAIN`, and `PROPOSE_ALTERNATIVE`. Silence, missing data, or failure to access a source must not be represented as agreement.

## 8. Publishing, privacy and licensing safeguards

- Public playlist titles and visible public post captions may be indexed with their URLs and observation date.
- Private chats, inboxes, account emails, phone numbers, personal details, private Drive documents, and non-public content must not be copied into public repositories or shared agent prompts without explicit permission.
- A link is not proof that its target is public, reusable, or licensed for republication.
- Preserve attribution and license information for code, media, transcripts, papers, and datasets.
- Do not auto-comment, send DMs, like, follow, subscribe, share, or change account settings as a background consequence of indexing.
- Draft public outreach messages and let a human approve before posting.
- Keep scientific claims distinct from symbolic Matrixgame metaphors, personal reflections, spiritual interpretations, and fiction.
